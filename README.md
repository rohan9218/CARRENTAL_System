🚗 Car Rental System (MERN Stack)

A full-stack Car Rental System built using the MERN Stack (MongoDB, Express.js, React.js, Node.js). This platform allows Owners, Vendors, and Customers to interact with the system for renting and managing cars efficiently.

📌 Project Overview
The system is designed with three main modules:
Owner
Vendor
Customer
Each module has its own functionalities and dashboard to manage operations smoothly.

👥 Modules & Features
🔹 1. Owner Module
View all cars listed on the platform
Monitor car status (available / booked)
Cannot remove cars once listed
Earn 20% platform commission from Vendor
View monthly revenue reports

🔹 2. Vendor Module
Add new cars to the platform
Update car details (status, availability, etc.)
Ensure cars have valid insurance
Pay 20% commission to Owner for platform usage
View monthly revenue reports

🔹 3. Customer Module
Browse available cars
View car details
Book cars بسهولة (easily)
Check availability status

💰 Revenue Model
Vendors must pay 20% of their earnings to the Owner as platform charges
Both Owner and Vendor can track their monthly revenue

✉️ Real-Time Email Features
This project includes real-time email functionality to improve user experience and communication.

🔹 Features Implemented:
📧 User Registration Email
When a user registers, a confirmation email is sent instantly
Helps verify user identity
🧾 Booking Receipt Email
After booking a car, the customer receives a detailed receipt via email
Includes booking details like:
Car name
Booking date & time
Total price
Vendor details

⚡ Real-Time Notification
Emails are triggered immediately after actions
Implemented using backend email services (e.g., Nodemailer)
